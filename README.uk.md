# Bloody Mouse Tray Light

[English](README.md) | [Русский](README.ru.md) | **Українська**

Нативна програма для Windows, написана на Rust. Вона показує заряд батареї, частоту опитування та DPI миші Bloody SG5 Pro у системному треї. Працює без запущеної Bloody Central; налаштування та історія повного заряджання зберігаються поруч із програмою.

## Запуск

Завантажте [`Bloody Mouse Tray Light.exe`](release/Bloody%20Mouse%20Tray%20Light.exe) і залиште поруч із ним файл [`mouse_tray.json`](release/mouse_tray.json). Програма призначена для 64-розрядної Windows.

За замовчуванням увімкнено російську мову інтерфейсу, темну тему та інтервал опитування 5 секунд. У налаштуваннях можна обрати українську або англійську мову.

## Збирання з вихідного коду

Потрібні Rust із MSVC toolchain і Microsoft Visual Studio C++ Build Tools. У кореневій папці репозиторію виконайте:

```powershell
cargo build --release
```

Готовий файл з’явиться тут: `target/release/bloody-mouse-tray-light.exe`.

## Основні можливості

- заряд Bloody SG5 Pro, кольоровий індикатор і режим значка батареї;
- частота опитування та DPI у підказці значка;
- українська, російська та англійська мови;
- журнал налагодження та запуск разом із Windows за вибором користувача.
